# 📚 מערכת לתיאום תורים לספרייה (Scheduling Library Appointments)

מערכת דיגיטלית נוחה ומודרנית המאפשרת לקוראים ולמבקרים בספרייה להזמין תורים מראש לשירותי הספרייה השונים, ומסייעת לצוות הספרייה בניהול יעיל של העומסים והזמנים.

---

## 🌟 תכונות מרכזיות

* **🎯 קביעת תור מהירה:** ממשק ידידותי לבחירת תאריך, שעה ושירות מבוקש.
* **⏱ ניהול עומסים ויעילות:** מנגנון המונע כפילויות ומבטיח סדר בקבלת הקהל.
* **📱 עיצוב רספונסיבי:** מותאם באופן מלא לצפייה ולשימוש הן במחשב והן במכשירים ניידים.
* **📊 ממשק נוח לצוות:** צפייה מסודרת בתורים המתוכננים לפי ימים ושעות.
